# Tauheed News - Frontend

Portal berita Islam pilihan berbasis Al-Qur'an dan Sunnah sesuai pemahaman Salafus Shalih. Sajian berita utama, kajian kitab, tuntunan Islam, dan analisis syar'i.

## Teknologi
- Next.js (App Router)
- React
- Tailwind CSS
- TypeScript

## Cara Menjalankan (Lokal)

1. Pastikan Anda sudah menginstall Node.js.
2. Buka terminal di folder ini.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Jalankan development server:
   ```bash
   npm run dev
   ```
5. Buka `http://localhost:3000` di browser.

*(Pastikan server backend juga berjalan agar data berita dan kajian dapat ditampilkan dengan benar).*
